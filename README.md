# 📑 My Personal Résumé Website

Welcome to the repository of my personal résumé website, built from scratch using semantic HTML5 and custom CSS3. This project showcases my professional background, technical stack, and clean-code development principles.

🔗 **[Live Demo — View My Résumé Here](https://oksanavakuliak.github.io/homepage/)**

---

## 🚀 About the Project

This is a responsive, lightweight single-page website developed as part of a technical assignment to master structured layout, responsive web design, and clean Git workflows (including branching strategy and Pull Requests).

### Key Features:

- **Responsive Layout:** Optimized for desktop and mobile devices via CSS Media Queries.
- **Semantic HTML:** Clean structural markup for better accessibility.
- **Custom Theming:** Built using native CSS variables for consistent design and coloring.

---

## 🛠 Tech Stack

- **Markup:** HTML5 (Semantic tags, SVG integration)
- **Styling:** CSS3 (Flexbox, Grid, CSS Variables, Media Queries)
- **Scripting:** JavaScript (ES6+, DOM Manipulation)
- **Workflow & Deploy:** Git, GitHub Projects, GitHub Pages
